# F5 — Verificación final de producción

**Lee:** STATE.md, INVENTORY.md (contratos), `manifest.json`, `dist/manifest.json`.

**Tareas**
1. `pnpm run typecheck && pnpm run test && pnpm run build`.
2. Crear `scripts/check-dist.mjs` (reutilizable): verifica que cada ruta de `dist/manifest.json` exista, que permisos/`host_permissions`/`matches` coincidan con INVENTORY, y busca en `dist/**/*.js` `eval(`, `new Function` y `https?://`. Revisar cada hit; los namespaces XML (`w3.org`) son falsos positivos. Añadir script `check:dist` a `package.json`.
3. Archivos heredados obsoletos (sin referencias en `src/` ni en el manifest): listarlos en STATE.md; **no borrar** sin confirmación del usuario.
4. Checklist manual en STATE.md, un ítem por entry point y contrato de INVENTORY. Incluir: cargar `dist/` sin empaquetar en `chrome://extensions`; abrir consola del service worker sin errores; forzar suspensión del SW (`chrome://serviceworker-internals` → Stop) y repetir un flujo de mensajería; probar content en una página dentro de `matches` y en una fuera; verificar `rem`/estilos de UI en Shadow DOM sobre 2 sitios distintos.

**Salida:** build limpio, `check:dist` sin hallazgos reales, STATE.md con lista de obsoletos y checklist.
