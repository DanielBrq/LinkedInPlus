# F3 — Content scripts

**Lee:** STATE.md, INVENTORY.md (filas content + selectores), solo los content scripts y utilidades DOM originales.
**Escribe:** `src/content/`, tests colocados.

**Tareas**
1. Migrar cada script: `null` checks estrictos en todo nodo DOM; conservar selectores originales; `MutationObserver` con `disconnect()` en cleanup.
2. Mensajería y storage solo vía `src/shared/`.
3. **Si hay UI inyectada:** host element con id único → `attachShadow({mode:'open'})` → montar Vue con `createApp` dentro del shadow → inyectar el CSS compilado (`import css from './x.css?inline'`) en un `<style>` del shadow root, con `:host { all: initial }`. Prohibido `<style>` en SFCs de content (se filtra a `document.head`); solo Tailwind. Nota: `rem` depende del `html` de la página anfitriona; anotar en STATE los casos donde el original usaba `px`.
4. Assets locales: `chrome.runtime.getURL()` + `web_accessible_resources` con `matches` mínimos.
5. Tests (happy-dom) solo donde haya lógica con ramas, Decision Models o contratos: manipulación DOM con y sin el nodo objetivo, mensajes con payload exacto. Prohibidos montaje trivial, mocks, constantes y duplicados.

**Salida:** typecheck y test en verde.
